# CALIVVS – California Burgers

Website and mobile web app for **CALIVVS**, a fictional California-style burger restaurant in Jeddah.
Group project for *Web & Mobile App. Development* (Dr. Mohammed Alsaigh).

- **Live site:** https://nisshi717.github.io/calivvs/ · **App:** https://nisshi717.github.io/calivvs/app/
- **Website:** `index.html` – Home, About Us, Menu, Offers, Contact
- **Mobile app:** `app/` – installable web app (order ahead, menu, offers, info)
- **Data source:** a [Google Sheet](https://docs.google.com/spreadsheets/d/1h65pRxK5DQvAvp0GsVK5-t4gUDoCORq0XZO1sUDha9s/edit?usp=sharing) with *Menu* and *Offers* tabs, read by `js/calivvs-data.js`.
  `data/calivvs-data.xlsx` is the original workbook; `data/menu-backup.js` is the saved copy used if the sheet can't be reached.

Built with HTML5, CSS3 and JavaScript – no frameworks.
